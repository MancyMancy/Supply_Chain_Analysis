This project explores 180,519 supply chain records across 53 features to uncover insights into product risk, bottlenecks, demand trends, and operational efficiency. Data was prepared, analyzed, and visualized entirely in Python, using libraries for data manipulation and visualization.

Revenue and cost analysis across product categories and regions

Bottleneck detection in procurement, manufacturing, and distribution

Root cause analysis of delays and inefficiencies

Time series forecasting for demand and supply fluctuations

Segmentation of suppliers and products for performance evaluation

Interactive Python‑based dashboards for visualization
